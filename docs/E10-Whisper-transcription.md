# E10 ART-AE Cloudflare Whisper transcription staging
User clicks "Расшифровать" below a voice message. The client first requests cached private transcription; if absent, downloads the authenticated original audio, decodes it locally, converts into independent mono 16 kHz PCM WAV segments of approximately 20 s, and POSTs each segment to the app's authenticated Netlify endpoint.
Netlify forwards each segment to Cloudflare Workers AI Whisper Large v3 Turbo using secrets on the server. Individual segment results are saved on Yandex Disk. Final text is joined and stored at the voice message path. Other members retrieve the saved text without rerunning AI. No PostgreSQL migration required.
Cloudflare env variables: CLOUDFLARE_ACCOUNT_ID (32 hex characters), CLOUDFLARE_AI_TOKEN (a Cloudflare API token granting Workers AI run/inference). Set via Netlify environment variables, NEVER in app.js or repository. Worker deployment is not needed: Workers AI's official REST endpoint is used directly. No credit card or paid upgrade should be enabled.
Caveats: browser decodeAudioData buffers the full recording, so hours-long recordings can run out of memory. Free quota is 10k Neurons/day across the account. Browser/server request timeouts and AI processing can cause incomplete work; saved segments let a later retry resume without paying for successful segments. Concurrent requests may race and create duplicate inference cost; consider distributed locks if usage grows.
Security: endpoint checks session, active conversation/project, and voice message. It accepts only bounded PCM WAV audio input, enforces same-origin POST and keeps Cloudflare token server-side. It cannot cryptographically prove client-supplied WAV content matches the committed voice file; with 2-5 trusted users the account-wide free quota is the practical cost ceiling. If user membership and paid usage are expanded, require strong input verification and rate limiting.
Local syntax and simulation tests should be run before enabling. Live Cloudflare credentials and iOS/Android transcoding are not verified yet.
