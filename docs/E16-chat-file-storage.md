# Chat files — ART-AE E16
Chat attachment storage is `<artae_projects.folder_path>/!ФайлыИзЧатов/` on Yandex Disk (created lazily at the first chat file upload).
Every object uses `<uuid>__<original filename>` to prevent collisions across conversations. The folder is hidden from the project file explorer by filtering list responses and rejecting direct traversal/creation by name. It remains visible in the native Yandex Disk UI.
The chat composer now opens a real file picker and retains selected files in an in-memory draft. When Send is pressed, files are uploaded via authenticated Netlify for <=3 MiB, or signed Yandex URLs for larger objects, and only then is a message committed. The message body includes stable `[[chatfile:v1:<uuid>:<encoded name>:<size>]]` references plus optional caption. Link rendering/download is restored from server messages after refresh. Voice and text-only messages are unaffected.
Current limitations: large uploads may be blocked by Yandex CORS; browsers may open signed download URLs rather than save immediately. The hidden folder is a UI isolation, not encryption; authenticated project members can access chat files. Orphan files from abandoned uploads are not yet garbage-collected. Test live with two participants before treating this as proven.
