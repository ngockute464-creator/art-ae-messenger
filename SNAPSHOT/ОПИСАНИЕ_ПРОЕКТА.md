# АРТ-АЕ — описание проекта по состоянию на 06.11.2026

## Назначение

Приватный PWA-мессенджер для небольшой группы (ориентир 2–5 пользователей), доступный в браузере Windows, Android и iOS. Продукт — компактная рабочая среда с проектами, разговорами, закреплениями, документами и голосовыми сообщениями, визуально ближе к Linear / Apple Notes, чем к загруженным корпоративным системам.

## Текущая схема размещения

1. **Netlify:** размещает статическую PWA и выполняет серверные функции `netlify/functions/*.mjs` (которые собираются/подменяются в процессе build).
2. **Supabase Free PostgreSQL:** таблицы `artae_users`, `artae_sessions`, `artae_projects`, `artae_conversations`, `artae_messages`, `artae_pins`, `artae_office_locks`.
3. **Supabase Realtime:** приватные WebSocket-каналы через подписанные сервером JWT, fallback — периодический опрос.
4. **Яндекс Диск:** документы, файлы проектов, скрытые для проводника вложения из чатов и голосовые.
5. **Cloudflare Workers AI:** распознавание голосовых через Whisper Large v3 Turbo. Вызов из серверной функции Netlify, не из браузера.
6. **VibeOffice:** сторонний браузерный редактор DOCX/XLSX, загружаемый при сборке из фиксированного GitHub-коммита. По умолчанию same-origin; отдельный домен/изоляция — экспериментальная возможность.

## Навигация и интерфейс

ПРОЕКТЫ → Проект → Разговор. Есть закрепления проекта и разговора, файловый проводник, просмотр/скачивание документов, редактирование названий, PWA-кэш и мобильная версия. На широком экране — многоколоночное расположение.

## Файловая модель

Каждый проект имеет `folder_path` в `artae_projects`, например `app:/<папка проекта>`. Обычные документы сохраняются в соответствующей папке или её подпапках.

Служебные папки:
- `!ФайлыИзЧатов` — автоматически создаваемая в корне проекта при первой загрузке вложения из чата; скрыта в проводнике приложения, но видна на Яндекс Диске; имя файла включает UUID.
- `_artae_voice` — сегменты голосовых записей.
- `_artae_edit_staging` — промежуточные копии больших редактируемых документов.

Операции с файловой системой должны проходить авторизацию и проверки проекта/разговора. Для крупных файлов предусмотрена прямая передача по короткоживущим URL Яндекс Диска; она **зависит от CORS браузера** и не является гарантированно испытанной.

## Сообщения, голосовые, редактирование

- Отправка сообщений использует собственный PostgreSQL API, UUID для защиты повторных отправок.
- Голосовые пишутся браузером, сохраняются частями на Яндекс Диск, воспроизводятся в чате; расшифровка по требованию, результат кэшируется.
- Документы DOCX/XLSX открываются в VibeOffice. Реализована отправка сохранённого файла обратно в Яндекс Диск с проверкой версии.
- Для предотвращения одновременного редактирования одного документа используется атомарная PostgreSQL lease-блокировка (120 секунд с продлением); доступ к ней идёт только через сервер.
- Папка `!ФайлыИзЧатов` скрывается в файловом проводнике; ссылки на вложения формируются в сообщениях.

## Авторизация и безопасность

Независимая от Supabase Auth авторизация, администратор управляет пользователями и ключами доступа, сессия в `__Host-artae_session` — Secure/HttpOnly/SameSite=Strict. Пользовательские ключи и сервисные токены не должны попадать в исходный ZIP или клиентские файлы.

## Ограничения и уровень проверки

- В момент архивирования Netlify Free заблокирован из-за исчерпания месячных кредитов. Это не означает проблему данных в Supabase.
- Последний коммит в GitHub **не доказывает**, что Netlify успел успешно его опубликовать.
- Загрузка больших файлов, Office round-trip, iOS/Android и одновременная работа нескольких устройств требуют живого теста.
- Действующий код зависит от Netlify Functions и сборочных патчей, поэтому **VPS-перенос ещё не выполнен**.
- По проверенным исходникам полноценная регистрация/отправка системных Web Push-уведомлений не подтверждена.
- Обновления кода/сборки/деплоя должны выполняться только по явному разрешению; данный архив никаких рабочих ресурсов не меняет.

## Внешние зависимости

Netlify, Supabase, Яндекс Диск, Cloudflare Workers AI, GitHub (фиксированная ревизия VibeOffice). Дамп базы, содержимое Яндекс Диска, Netlify-переменные окружения и исходные секретные ключи **не входят** в архив исходников.
