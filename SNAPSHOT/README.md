## Быстрый ориентир

- `SNAPSHOT/ОПИСАНИЕ_ПРОЕКТА.md` — назначение, архитектура, работа компонентов, ограничения.
- `SNAPSHOT/ИНСТРУКЦИЯ_ПО_СБОРКЕ.md` — **точная существующая схема сборки для Netlify** и локальная подготовка.
- `SNAPSHOT/ПЕРЕМЕННЫЕ_ОКРУЖЕНИЯ.example` — названия переменных, без ключей и паролей.
- `SNAPSHOT/МАНИФЕСТ.md` — зафиксированная ревизия и состав, границы резервирования.
- `netlify.toml` — исходные параметры публикации.
- `artae.zip` — **вложенный исходный базовый ZIP**, используемый скриптом сборки. Не заменять и не удалять его.
- `build/prepare.mjs` — актуальные изменения/патчи поверх базового ZIP.
- `office-site/` — отдельный эксперимент с изолированным редактором.
- `docs/` — оригинальные технические заметки.
- `sql/` — SQL-схемы и миграции.

Это архив **исходников**, а не экспорт аккаунтов, секретов или содержимого сторонних хранилищ. Для запуска потребуются значения переменных окружения и работающие аккаунты Supabase / Яндекс Диска / Cloudflare. Входящие в репозиторий исходники **не являются готовой сборкой для VPS**.
